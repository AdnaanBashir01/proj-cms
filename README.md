A clean, minimalist content management dashboard built with React, JavaScript, and CSS, backed by a custom Node.js REST API with persistent JSON storage. Fully offline — no external services or databases required.

Features
📊 Dashboard with article stats, publishing progress, and recent activity
📝 Full CRUD — create, edit, publish/unpublish, delete articles
📋 Data table with search, filters, sorting, pagination, and bulk actions
✏️ Reusable article form with validation, tags, image upload/URL, and live preview
👥 Category and team management with roles
⚙️ Settings with white-tone themes and interface sizing (small/medium/large)
🔔 Loading, error, empty, toast, and confirmation states throughout
📱 Fully responsive glassmorphism UI with Fredoka font
