A clean, minimalist Content Management System dashboard built with React, JavaScript, and CSS, backed by a custom Node.js REST API with persistent JSON storage.

The application provides a complete admin interface for creating, managing, organizing, and publishing articles. It is designed to run fully offline, with no external services or databases required.

Features
 Dashboard with article statistics, publishing progress, and recent activity.
<br>

 Full CRUD functionality — create, edit, publish/unpublish, and delete articles.
<br>

 Data table with search, filters, sorting, pagination, and bulk actions.
<br>

 Reusable article form with validation, tags, image upload/URL support, and live preview.
<br>

 Category and team management with role-based organization.
<br>

 Settings with white-tone themes and interface sizing options (Small / Medium / Large).
<br>

 User feedback states including loading, error, empty, toast, and confirmation states.
<br>

Fully responsive UI with a minimalist glassmorphism design and Fredoka font.
